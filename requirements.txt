# INSTALLATION NOTES:
# 
# 1. After installing requirements, run these additional commands:
#    playwright install chromium
# 
# 2. Ensure Tesseract OCR is installed on your system:
#    Windows: Download from https://github.com/UB-Mannheim/tesseract/wiki
#    Linux: sudo apt install tesseract-ocr tesseract-ocr-kan
#    macOS: brew install tesseract tesseract-lang
# 
# 3. Ensure Poppler is installed for PDF to image conversion:
#    Windows: Download from https://blog.alivate.com.au/poppler-windows/
#    Linux: sudo apt install poppler-utils
#    macOS: brew install poppler
# 
# 4. For production deployment, uncomment Google Cloud dependencies
#    if you plan to use Google Cloud Document AI services
